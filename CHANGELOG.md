# Changelog

## 0.1.0

First release.

- `run`, `record` and `compose` commands.
- Step events from a local HTTP endpoint, a tailed JSONL file, or a polled command.
- Zero-dependency `mark()` / `message()` / `done()` SDK at `@askeleven/agent-proof/mark`.
- Per-step speed ramp with minimum and maximum screen time and lead-in trim.
- Hook intro card, step bar, and an optional chat panel fed by message events.
- Toy example that runs with no API keys.
